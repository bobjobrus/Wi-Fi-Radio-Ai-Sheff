# Прошивка и настройка

От голой платы до рации в эфире — и как ею пользоваться каждый день.

**Перед началом**

- **Мост уже работает**, и вы знаете его адрес и ключ сети — см. [Свой мост](BRIDGE.md). Мост — небольшая программа
  на компьютере или сервере, через которую рации слышат друг друга. Без моста рация включится, но в эфир не выйдет.
- **Плата** — ESP32-S3-DevKitC-1 или её клон YD-ESP32-S3, флеш-память от 4 МБ (PSRAM прошивке не нужна).
  Провода — как в [сборке](BUILD.md).
- **Кабель USB-C с передачей данных.** Кабель «только для зарядки» плату компьютеру не покажет.

Прошить и настроить плату можно ещё до сборки корпуса: чтобы выйти в сеть, микрофон и динамик не нужны.

## 1. Прошивка

Прошивка — программа внутри платы. По кабелю её записывают один раз, дальше рация обновляется сама
через мост ([раздел 4](#4-обновления)).

### Какой файл брать

| Файл | Что внутри | Когда нужен |
|---|---|---|
| [`firmware/dist/walkie-full-v9.bin`](../firmware/dist/walkie-full-v9.bin) | вся флеш-память, 4 МБ: загрузчик, таблица разделов и сама программа версии 9 | первая прошивка по кабелю и «спасение» платы, которая не запускается. Пишется с адреса `0x0`. **Стирает все настройки рации** |
| [`firmware/dist/walkie.bin`](../firmware/dist/walkie.bin) + [`walkie.json`](../firmware/dist/walkie.json) | только программа (≈1,2 МБ) и номер её версии | для моста, чтобы рации обновились сами, и для загрузки через страницу настроек |

### Гнёзда USB и порт

У платы два гнезда USB-C:

- **«USB»** — встроенный USB самого ESP32-S3. Им удобнее всего и прошивать, и настраивать.
- **«COM»** (на оригинальной плате подписано «UART») — через отдельную микросхему-переходник. На некоторых клонах
  через это гнездо плата **не получает питания от кабеля C–C**: на плате не хватает резисторов, по которым
  компьютер понимает, что к нему подключили устройство. Плата не загорается — переходите на гнездо «USB»
  или возьмите кабель USB-A → USB-C.

Порт — имя, под которым компьютер видит подключённую плату:

| Система | Как выглядит порт |
|---|---|
| macOS | `/dev/cu.usbmodem…`, `/dev/cu.wchusbserial…` или `/dev/cu.usbserial…` |
| Linux | `/dev/ttyACM0` или `/dev/ttyUSB0`. Один раз добавьте себя в группу `dialout`: `sudo usermod -aG dialout $USER` и перезайдите в систему |
| Windows | `COM3`, `COM5`… — «Диспетчер устройств → Порты (COM и LPT)». Если гнездо «COM» не даёт порта, поставьте драйвер его микросхемы-переходника — CH343 с сайта WCH (клон YD-ESP32-S3) или CP210x с сайта Silicon Labs (оригинальная DevKitC-1), — или подключитесь к гнезду «USB» |

Не знаете, какой порт ваш, — посмотрите список до и после подключения кабеля: новый и есть плата.

В собранной рации гнёзда платы внутри корпуса — снимите заднюю крышку (4 шурупа). Перед подключением кабеля
к плате выключите тумблер (выключатель питания сверху): рация будет питаться от компьютера, а аккумулятор
не будет зря разряжаться.

### Вариант А. Готовый файл через esptool

esptool — официальная программа Espressif для записи прошивки, работает на macOS, Linux и Windows. Нужен Python 3.

```sh
python3 -m pip install --upgrade esptool
```

macOS и Linux (порт подставьте свой):

```sh
esptool --chip esp32s3 --port /dev/cu.usbmodem1101 --baud 921600 --after watchdog-reset \
  write-flash 0x0 firmware/dist/walkie-full-v9.bin
```

Windows (PowerShell):

```powershell
python -m esptool --chip esp32s3 --port COM5 --baud 921600 --after watchdog-reset write-flash 0x0 firmware\dist\walkie-full-v9.bin
```

- `0x0` — писать с самого начала памяти: в файле всё сразу, включая загрузчик.
- `--after watchdog-reset` — после записи перезапустить плату так, чтобы она точно вышла из режима загрузки.
  Обычный сброс через гнездо «USB» иногда оставляет её в загрузчике, и рация молчит.
- Это написание для esptool 5. Если команда не понимает `write-flash` или `watchdog-reset`, у вас старая
  версия — обновите её командой выше.

**macOS, коротко:** [`tools/flash.sh`](../tools/flash.sh) сам находит порт и самый свежий
`walkie-full-v*.bin` и запускает ту же команду (`tools/flash.sh /dev/cu.xxx` — указать порт вручную).
Скрипт берёт esptool из ядра Arduino, поэтому один раз должен отработать
[`tools/build_firmware.sh`](../tools/build_firmware.sh) (вариант Б ниже).

### Вариант А2. В браузере, без установки программ

Нужен Chrome или Edge на компьютере: только они умеют работать с USB-портами из страницы (Safari и Firefox — нет).

1. Откройте официальный веб-прошивальщик Espressif: <https://espressif.github.io/esptool-js/>.
2. Baudrate `921600` → **Connect** → выберите порт платы.
3. Flash Address `0x0`, файл `walkie-full-v9.bin` → **Program**.
4. Когда запись закончится, нажмите на плате **RST** (или выньте и вставьте кабель).

### Вариант Б. Собрать прошивку самому

Нужно, если вы поменяли код или хотите вшить адрес своего моста.

**Что можно поменять перед сборкой** — в [`firmware/walkie/config.h`](../firmware/walkie/config.h):

- `FW_VERSION` — номер версии, целое число. Каждую новую сборку для моста делайте с номером **больше**,
  иначе рации её не возьмут.
- `DEFAULT_SERVER` — адрес вашего моста, например `"radio.example.com"`. Тогда свежепрошитые рации знают мост
  без настройки. Адрес, введённый потом на странице или по USB, важнее вшитого; после команды `factory`
  рация возвращается к вшитому адресу. Ключ сети в прошивку
  не вшивается никогда — его вводят отдельно.
- Номера выводов — если вы развели плату по-другому.

**macOS и Linux:**

1. Поставьте arduino-cli: на macOS `brew install arduino-cli`, на Linux — по
   [официальной инструкции](https://arduino.github.io/arduino-cli/latest/installation/).
2. Запустите сборку:

   ```sh
   tools/build_firmware.sh
   ```

   В первый раз скрипт сам поставит ядро esp32 версии 3.3.12 (несколько сотен мегабайт). Сторонних библиотек
   прошивке не нужно. Результат — в `firmware/dist/`: `walkie-full-vN.bin`, `walkie.bin` и `walkie.json`.

Настройки платы, с которыми собирает скрипт: «ESP32S3 Dev Module», Flash Size 4M, разметка памяти
`min_spiffs` (две половины по 1,9 МБ — нужны для обновления по воздуху), PSRAM выключена, USB Mode `hwcdc`,
USB CDC On Boot включён.

> Скрипт подменяет служебную программу ctags пустышкой: на Mac с Apple Silicon без Rosetta та, что идёт с Arduino,
> не запускается. Поэтому в `walkie.ino` каждая функция должна стоять **до** того места, где её вызывают, —
> иначе сборка не пройдёт.

**Windows** (PowerShell, из папки проекта):

```powershell
arduino-cli core install esp32:esp32@3.3.12 --additional-urls https://espressif.github.io/arduino-esp32/package_esp32_index.json
arduino-cli compile --fqbn "esp32:esp32:esp32s3:FlashSize=4M,PartitionScheme=min_spiffs,PSRAM=disabled,USBMode=hwcdc,CDCOnBoot=cdc" --output-dir firmware\build firmware\walkie
```

В `firmware\build` появятся `walkie.ino.merged.bin` (это и есть полный образ, как `walkie-full`) и `walkie.ino.bin`
(это `walkie.bin`). `walkie.json` для моста создайте сами: `{"version": 9}` — число из `FW_VERSION`.

**Arduino IDE 2** тоже подойдёт. Ядро «esp32 by Espressif» 3.3.12, в меню «Инструменты»:
плата «ESP32S3 Dev Module», Flash Size «4MB (32Mb)», Partition Scheme «Minimal SPIFFS (1.9MB APP with OTA/190KB SPIFFS)»,
PSRAM «Disabled», USB Mode «Hardware CDC and JTAG», USB CDC On Boot «Enabled».
Файлы — через «Скетч → Экспорт скомпилированного бинарного файла».

### Если не прошивается

- **Порт не появляется** — кабель без передачи данных, или гнездо «COM» без питания (см. выше). Попробуйте
  другой кабель и гнездо «USB».
- **`Failed to connect` / `No serial data received`** — переведите плату в режим загрузки руками: зажмите **BOOT**,
  нажмите и отпустите **RST**, отпустите **BOOT**. Повторите команду.
- **Ошибки посреди записи** — уменьшите скорость: `--baud 115200`.
- **Записалось, но кольцо не горит** — нажмите **RST** или переподключите кабель.

## 2. Первая настройка

Рации нужно знать три вещи — Wi-Fi, адрес моста и ключ сети — и, для удобства, своё имя.

| Что | Где взять |
|---|---|
| **Адрес моста** | IP или доменное имя сервера, где работает мост: `203.0.113.10` или `radio.example.com`. Порт по умолчанию 47000; другой — через двоеточие: `radio.example.com:47010`. Если мост в той же сети, что и рация, поле можно оставить пустым ([ниже](#пустой-адрес-моста--поиск-в-своей-сети)) |
| **Ключ сети** | общий пароль всех раций и мостов — строка `key` в настройках моста. Новый ключ выдаёт `python3 hub/walkie_hub.py --genkey`. Нужно не меньше 12 **латинских** букв и цифр (русские буквы рация пропускает, а мост учитывает — ключи не сойдутся); дефисы, пробелы и регистр не важны: `abcd-efgh…` и `ABCDEFGH…` — один и тот же ключ |
| **Wi-Fi** | имя сети и пароль. Только **2,4 ГГц**: сети 5 ГГц ESP32-S3 не видит. Не подойдут сети со входом через страницу (как в кафе и гостиницах) и корпоративные с логином |
| **Имя** | как рацию будет видно на странице моста: «Кухня», «Гараж». Без имени — «Рация XXXX». Влезает 31 байт: около 15 русских букв или 31 латинская |

Ключ хранится в памяти рации, а не в прошивке. Каждый пакет подписан этим ключом, речь зашифрована: рация
с другим ключом в эфир не попадёт.

### Способ 1. По USB-кабелю (macOS, Linux)

[`tools/provision.py`](../tools/provision.py) — только стандартный Python 3, ставить ничего не нужно.

```sh
python3 tools/provision.py --name Кухня --server 203.0.113.10 --key XXXX-XXXX-XXXX-XXXX
python3 tools/provision.py --wifi "ИмяСети|пароль" --wifi "ВтораяСеть|пароль2"
python3 tools/provision.py --show
```

| Ключ | Что делает |
|---|---|
| `--name` | имя рации |
| `--server` | адрес моста `хост[:порт]`; `auto` — стереть адрес и искать мост в своей сети |
| `--key` | ключ сети |
| `--wifi "Сеть\|пароль"` | добавить сеть; можно повторить, рация помнит до трёх сетей |
| `--volume 0..20` | громкость |
| `--amp i2s` / `--amp pdm` | тип усилителя: `i2s` — MAX98357A (по умолчанию), `pdm` — PAM8403 через фильтр. Рация перезапустится, поэтому скрипт делает это последним |
| `--show` | показать состояние рации (то же, что запуск без ключей) |
| `--reboot` | перезапустить рацию в конце |
| `--port` | указать порт вручную |

Порт скрипт находит сам только на macOS. На Linux укажите его: `--port /dev/ttyACM0`. На каждый шаг скрипт
печатает ✓ или ✗; ключ и пароли в выводе заменены на `***`.

На Windows скрипт не работает (ему нужен модуль termios, который есть только в macOS и Linux) — введите те же
команды в окне порта, см. [раздел 5](#5-команды-по-usb).

### Способ 2. С телефона

Рация, которая не знает ни одной Wi-Fi-сети, открывает свою **точку доступа** — Wi-Fi-сеть `RADIO-XXXX`
без пароля (XXXX — четыре знака номера рации). Кольцо при этом медленно «дышит» фиолетовым.

1. Включите рацию и подключите телефон к сети `RADIO-XXXX`.
2. Страница настройки откроется сама, как в гостиничном Wi-Fi. Не открылась — наберите в браузере
   `http://192.168.4.1`.
3. Блок **«Настройки»**: имя, адрес моста, ключ сети → **«Сохранить»**.
   Сделайте это до Wi-Fi: после Wi-Fi рация перезапустится, и телефон от неё отключится.
4. Блок **«Wi-Fi»**: **«Найти»** → нажмите на свою сеть → пароль → **«Подключиться к этой сети»**.
   Рация запомнит сеть, перезапустится и подключится.
5. Через несколько секунд прозвучит «ти-ду» вверх — рация на связи с мостом.

Если сначала ввели Wi-Fi, а ключ остался пустым, после перезапуска рация снова откроет `RADIO-XXXX`
(Wi-Fi есть, ключа нет): подключитесь ещё раз и закончите шаг 3. Можно и через домашнюю сеть — см. ниже.

Точка доступа закрывается сама, когда рация больше минуты подключена к Wi-Fi, на связи с мостом и к точке
никто не подключён.

### Страница настроек в домашней сети

Та же страница открывается с любого устройства в той же Wi-Fi-сети по адресу `http://radio-xxxx.local`
(те же четыре знака, маленькими буквами). С компьютеров и iPhone обычно открывается; Android такие адреса
часто не понимает — тогда найдите `radio-xxxx` в списке устройств роутера и наберите его адрес цифрами
(или посмотрите его командой `show` по USB).

Блок **«Состояние»** обновляется каждые 2 секунды: связь («на связи», «ищу мост», «не тот ключ сети»…), заряд,
сеть и сила сигнала, мост и задержка до него, сколько раций в сети, принятые и потерянные пакеты, «Чужие
пакеты» (с неверной подписью), «Работает» — сколько времени и почему рация запустилась в последний раз
(включение питания, сторож, просадка питания…), «Свист рядом с другой рацией» и последняя ошибка.

| Поле | Что делает | По умолчанию |
|---|---|---|
| Имя рации | так её видно на странице моста | «Рация XXXX» |
| Адрес моста | `хост[:порт]`; пусто — искать мост в своей сети | пусто |
| Ключ сети | поле всегда показывается пустым; рядом написано «задан» или «не задан». Оставьте пустым, чтобы не менять | — |
| Громкость | 0–20, шаг ≈ 2 дБ | 14 |
| Яркость подсветки | кольцо, 0–100 | 60 |
| Автоусиление микрофона | рация сама подстраивает чувствительность под голос (до +36 дБ) | вкл. |
| Усиление, если автоусиление выключено | 0–42 дБ | 24 |
| Сигнал в конце чужой передачи | короткое «ти-ду» вниз, когда собеседник отпустил кнопку | вкл. |
| Микрофон на правом канале | если вывод L/R микрофона INMP441 подключён к 3,3 В, а не к GND. Проверить — командой `micraw` | выкл. |
| Регулятор крутится наоборот | если по часовой стрелке громкость уменьшается | выкл. |
| Экономия аккумулятора | после 15 с тишины Wi-Fi дремлет; первые слова входящей передачи приходят с задержкой до ≈0,3 с (буфер её сглаживает), аккумулятор живёт дольше | **выкл.** |

> **Экономию включайте с осторожностью.** В простое рация тогда берёт так мало тока, что модуль заряда,
> устроенный как пауэрбанк, может решить, что нагрузку отключили, и выключить питание: рация «выключится сама».
> Проверьте свой модуль: включите экономию и оставьте рацию на аккумуляторе в покое на полчаса.

Переключателя типа усилителя на странице нет — только по USB (`amp`, см. [раздел 5](#5-команды-по-usb)).

> **У страницы нет пароля.** Любой, кто в той же Wi-Fi-сети (или подключился к открытой `RADIO-XXXX`), может
> поменять настройки и загрузить прошивку. Сам ключ сети страница не показывает никогда. Держите рации в своей
> сети, а не в общественной.

### Wi-Fi: до трёх сетей

- Рация помнит **до трёх сетей**, например дом, дачу и мастерскую, и при подключении выбирает ту знакомую, что ловит
  лучше. Четвёртая вытесняет первую в списке. Лишнюю можно убрать кнопкой «убрать» на странице.
- Сеть пропала — рация пробует подключиться каждые 15 секунд. Через минуту без сети она дополнительно открывает
  `RADIO-XXXX`, чтобы можно было дать ей новую сеть. Если сеть просто временно пропала — ничего не трогайте:
  вернётся сеть — рация подключится сама.
- 15 минут без Wi-Fi, и к точке никто не подключён, — рация перезапускается сама.

### Пустой адрес моста — поиск в своей сети

Если адрес пуст (или по USB задано `server auto`), рация рассылает приветствие всем устройствам своей сети
на UDP-порт 47000 и берёт первый мост, который ответил с тем же ключом. Это работает, только когда мост
стоит в той же сети, за тем же роутером. Не сработает, если рация в другом месте, в гостевой сети с изоляцией
устройств или если роутер не пропускает широковещательные пакеты — тогда впишите адрес.

Если адрес задан, рация говорит только с ним. Доменное имя она переспрашивает раз в 10 минут (и каждые 15 секунд,
пока связи нет): сменился IP сервера — достаточно поправить одну запись у регистратора домена, рации найдут
мост сами.

### Снова открыть настройку кнопкой

Зажмите кнопку «говорить», включите тумблер и держите кнопку около 1,5 секунды, пока кольцо не нальётся
фиолетовым. Рация откроет `RADIO-XXXX` и одновременно подключится к знакомой сети. Низкий гудок после этого —
нормально: кнопку держали, пока связи ещё не было. В этом режиме точка доступа работает до выключения —
закончили, выключите и включите рацию.

## 3. Пользование

### Первая проверка одной рацией

Вторая рация для проверки не обязательна: на компьютере можно запустить «попугая», который возвращает в эфир
всё сказанное.

```sh
python3 hub/sim_radio.py --hub 203.0.113.10 --key XXXX-XXXX-XXXX-XXXX echo
```

Нажмите кнопку, скажите что-нибудь, отпустите — через мгновение рация повторит ваши слова. «Попугай» работает
30 минут (`--minutes` меняет срок). Другие проверки той же программой — `status`, `tone`, `say`, `listen`:
`python3 hub/sim_radio.py --help`. Компьютеру нужен доступ к мосту по UDP, как и рациям.

### Говорить

1. Нажмите и держите кнопку «говорить». По кольцу бегут два белых огонька — рация просит у моста эфир.
2. Прозвучит «пи-пи» вверх — можно говорить. Сказанное до сигнала не передаётся.
3. Говорите обычным голосом. Кольцо красное и «пляшет» в такт голосу — вас слышно.
4. Отпустите кнопку. Остальные рации слышат вас сразу, пока вы говорите, а не после.

Говорит один человек за раз. Если эфир занят, прозвучит «бу-бу-бу» — дождитесь конца чужой передачи и нажмите
снова. Одно нажатие — не дольше 90 секунд (защита от залипшей кнопки; срок задаёт строка `tot_seconds`
в настройках моста, но больше 100 секунд рация всё равно не передаёт): потом низкий гудок — отпустите и нажмите заново.

### Регулятор

| Действие | Что происходит |
|---|---|
| Повернуть | громкость, по одному шагу на щелчок (0–20). На 1,5 с кольцо показывает уровень, слышен щелчок. Поворот заодно включает выключенный звук |
| Коротко нажать (меньше 1 с) | выключить или включить звук. Пока звук выключен, в простое горит один фиолетовый огонёк; если в это время кто-то говорит, кольцо мягко светится голубым |
| Подержать 1–4 с и отпустить | на 2,5 с — шкала заряда: зелёная — больше 40 %, янтарная — 16–40 %, красная — 15 % и меньше. Тусклое белое — заряд ещё измеряется, синее — питание от USB без аккумулятора |
| Подержать 10 с | сброс настроек ([ниже](#сброс-настроек)). С 5-й секунды кольцо мигает красным: передумали — отпустите, ничего не случится |

Крутится «не в ту сторону» — включите «Регулятор крутится наоборот» на странице настроек.

### Звуки

| Звук | Значит |
|---|---|
| «пи-пи» вверх | можно говорить |
| «бу-бу-бу» | эфир занят |
| один низкий гудок | связи нет, мост не ответил на нажатие или кнопку держали дольше 90 с |
| два тона вниз | пропала связь с мостом |
| «ти-ду» вверх | рация вышла на связь: после включения или когда связь вернулась |
| короткое «ти-ду» вниз | чужая передача закончилась (отключается настройкой «Сигнал в конце чужой передачи») |
| щелчок | громкость изменилась или звук включён |
| три нисходящие ноты | садится аккумулятор |

### Кольцо

В простое — короткая зелёная вспышка раз в 3 секунды: всё в порядке. Что значат остальные цвета —
в таблице [Цвета кольца](TROUBLESHOOTING.md#цвета-кольца).

### Аккумулятор и зарядка

- **Зарядка** — кабелем в гнездо USB-C внизу корпуса (модуль заряда). Рация заряжается и при выключенном тумблере:
  тумблер отключает только питание рации. Пока заряжается, ею обычно можно пользоваться — это зависит от модуля
  заряда. Проценты во время зарядки завышены: напряжение под зарядом выше — точное значение появится примерно
  через минуту после отключения кабеля.
- **Сколько осталось** — подержать регулятор 1–4 с; на странице настроек — строка «Аккумулятор» (проценты и вольты);
  на странице моста видно заряд всех раций сразу.
- Первые ≈20 секунд после включения заряд «измеряется»: пока Wi-Fi подключается, напряжение гуляет. Во время
  разговора замеры тоже не учитываются — под нагрузкой напряжение проседает.
- **Садится:** если заряд 15 % и меньше держится 30 секунд, рация раз в 5 минут играет три нисходящие ноты
  (с 5 % — раз в минуту; во время разговора молчит), а в простое вспыхивает красным вместо зелёного.
  В журнал моста пишется «пора на зарядку».

### Сброс настроек

| Как | Что стирается | Что остаётся |
|---|---|---|
| Регулятор держать 10 с | Wi-Fi-сети, громкость, яркость, настройки микрофона и сигналов, направление регулятора, экономия | имя, адрес моста, ключ сети, тип усилителя |
| Команда `factory` по USB | всё | ничего: рация как новая |
| Прошивка `walkie-full-…bin` по кабелю | всё | ничего |

После сброса рация перезапускается и открывает `RADIO-XXXX` — настройте Wi-Fi заново ([раздел 2](#2-первая-настройка)).
Сброс регулятором не трогает ключ и адрес моста специально: после него рацию вернёт в эфир любой, кто знает пароль
от Wi-Fi.

## 4. Обновления

### Сама с моста

Мост сообщает каждой рации номер прошивки, которая лежит у него в папке. Если он больше номера рации,
рация ждёт, пока в эфире 20 секунд тихо (никто не говорит и не говорил), и тогда:

1. скачивает файл с моста по HTTP (порт 47080, если в мосте не задан другой);
2. сверяет размер и контрольную сумму SHA-256 — её рация получила в пакете, подписанном ключом сети, поэтому
   без ключа чужой файл ей не подсунуть;
3. записывает прошивку в другую половину памяти (не ту, с которой работает сейчас) и перезапускается уже с ней.

Пока идёт обновление, по кольцу растёт синяя полоса — не выключайте рацию. Настройки сохраняются.
Если загрузка оборвалась или файл не сошёлся, рация остаётся на старой прошивке (она лежит в другой половине
памяти и не тронута) и пробует снова через час или после перезапуска.

Как выложить прошивку на мост — в [Свой мост](BRIDGE.md). Коротко: соберите прошивку с бо́льшим `FW_VERSION`
([вариант Б](#вариант-б-собрать-прошивку-самому)) и положите в папку прошивок моста сначала `walkie.json`, потом
`walkie.bin` — мост заметит их в течение 10 секунд. Порядок важен: мост перечитывает папку, только когда меняется
`walkie.bin` ([подробнее](BRIDGE.md#9-обновление-прошивки-по-воздуху)). Скрипт сборки сам пишет в `walkie.json`
тот же номер, что в `config.h`.

Версию прошивки рации видно на странице настроек (блок «Прошивка») и в команде `show`.

### Вручную через страницу настроек

Блок **«Прошивка»** → выберите файл `walkie.bin` → **«Загрузить прошивку»**. Рация ответит «Прошивка записана,
перезапуск…» и перезапустится; настройки сохранятся. Номер версии здесь не проверяется — загрузится любая сборка
этой прошивки.

Загружайте именно `walkie.bin`, а не `walkie-full-…bin`: полный образ (4 МБ) не помещается в половину памяти
(1,9 МБ), и рация ответит «Ошибка записи прошивки».

### По кабелю

Если рация не запускается совсем, запишите полный образ заново ([раздел 1](#1-прошивка)). Настройки при этом
сотрутся.

## 5. Команды по USB

Рация принимает текстовые команды по кабелю через любое из двух гнёзд. Скорость — 115200 (для гнезда «COM»;
гнезду «USB» скорость не важна). Одна строка — одна команда, в конце Enter. Туда же рация пишет свой журнал:
что с Wi-Fi, мостом, обновлениями. Если что-то не так, первым делом смотрите сюда.

**Чем подключиться:**

- Любая система, где стоит esptool (с ним ставится и pyserial):

  ```sh
  python3 -m serial.tools.miniterm --echo /dev/cu.usbmodem1101 115200
  ```

  На Windows: `python -m serial.tools.miniterm --echo COM5 115200`. Выход — `Ctrl+]`.
- Arduino IDE: «Монитор порта», скорость 115200, конец строки — «Новая строка» (с «Нет конца строки» команды
  не выполняются).
- arduino-cli: `arduino-cli monitor -p /dev/ttyACM0 -c baudrate=115200`.
- Только посмотреть состояние на macOS и Linux: `python3 tools/provision.py --show` (на Linux — с `--port /dev/ttyACM0`).

| Команда | Что делает |
|---|---|
| `help` | список команд |
| `show` | всё о рации: номер, имя, версия прошивки, мост, ключ задан или нет, Wi-Fi, задержка, заряд, громкость, статистика приёма |
| `name Кухня` | имя рации |
| `server 203.0.113.10`<br>`server radio.example.com:47010` | адрес моста |
| `server auto` | стереть адрес: искать мост в своей сети |
| `key XXXX-XXXX-XXXX-XXXX` | ключ сети. Меньше 12 латинских букв и цифр — ответ `ERR key` |
| `wifi ИмяСети\|пароль` | добавить сеть (у знакомой — сменить пароль) и сразу подключиться. Сеть без пароля — `wifi ИмяСети` |
| `wifi-clear` | забыть все сети |
| `volume 14` | громкость 0–20 |
| `agc on` / `agc off` | автоусиление микрофона |
| `led 60` | яркость кольца 0–100 |
| `amp i2s` / `amp pdm` | тип усилителя: MAX98357A (по умолчанию) или PAM8403 через фильтр. Рация перезапустится |
| `testtx 5 1000` | 5 с передавать в эфир тон 1000 Гц, как будто нажата кнопка: проверка передачи без кнопки и микрофона. 1–20 с (по умолчанию 3), 100–4000 Гц (по умолчанию 1000) |
| `testmic 10` | 10 с передавать в эфир живой микрофон без кнопки: 1–80 с (по умолчанию 10) |
| `micraw` | за 1 секунду показывает размах «сырых» отсчётов микрофона на левом (L) и правом (R) каналах |
| `reboot` | перезапуск |
| `factory` | полный сброс: стирает всё, включая ключ и адрес моста ([сброс](#сброс-настроек)) |

На каждую команду, кроме `help` и `show`, рация отвечает строкой `OK …` или `ERR …`; неизвестная команда
(или `name` без имени) — `ERR неизвестная команда`.

**Как читать `show`.** Строка «связь: N» — число: `0` нет Wi-Fi, `1` нет ключа, `2` ищет мост, `3` не тот ключ
сети, `4` на связи. «мост:» — адрес, с которым рация работает сейчас; «адрес в настройках» — что вписано
(пусто — поиск в своей сети). «чужих пакетов» — пакеты с неверной подписью: растёт — рации отвечает мост или устройство с другим ключом.

**Как читать `micraw`.** Пока команда работает, говорите в микрофон или постучите по нему. Канал, к которому
подключён микрофон, покажет широкий размах чисел, другой — около нуля или одно и то же число. Сигнал на R —
включите «Микрофон на правом канале» или пересадите вывод L/R микрофона на GND.

`testtx` и `testmic` работают, только когда рация на связи с мостом; без связи будет низкий гудок, как при обычном
нажатии. Услышать тон можно второй рацией или записать эфир на компьютере:
`python3 hub/sim_radio.py --hub 203.0.113.10 --key XXXX-XXXX-XXXX-XXXX listen --seconds 30 --out efir.wav`.

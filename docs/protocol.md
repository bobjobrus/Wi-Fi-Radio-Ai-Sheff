# Протокол раций «WT1»

Один UDP-порт моста (по умолчанию **47000**). Рация шлёт со своего порта 47001.
Всё little-endian. Код: `hub/wt_proto.py` (эталон) и `firmware/walkie/protocol.h` — **менять вместе**.

## Пакет

```
'W' 'T' | версия=1 (1) | тип (1) | src (4) | данные … | подпись (8)
```

* `src` — id рации (FNV-1a от MAC) или id моста (sha256 от имени моста).
* Подпись — первые 8 байт HMAC-SHA256(k_auth, всё до подписи).
* Ключ сети — строка вроде `K7Q2-MX9P-4RTA-W8HD`; регистр, пробелы и дефисы не важны.
  `k_auth = HMAC-SHA256(ключ, "wt1-auth")`, `k_enc = HMAC-SHA256(ключ, "wt1-enc")[:16]`.
* Исключение: `BAD_KEY` (0x7F) — только заголовок, без подписи: мост так подсказывает рации,
  что её подпись не сошлась («не тот ключ сети»).

## Типы

| Тип | Кто → кому | Данные |
|---|---|---|
| `HELLO` 0x01 | рация → мост, раз в 2 с (без моста — раз в 1 с, широковещательно) | fw u16, flags u8 (1 = звук выключен), rssi i8, t_ms u32, rtt u16, имя (длина u8 + UTF-8 ≤ 31), заряд u8 (0–100 %, 255 — не от аккумулятора; необязательный) |
| `HELLO_ACK` 0x02 | мост → рация | t_echo u32, раций в сети u8, мостов в списке u8, мостов на связи u8, эфир занят u8, версия прошивки u16, размер u32, sha256 32 байта, http-порт u16, имя моста |
| `TALK_REQ` 0x10 | рация → мост (повтор каждые 150 мс, до 700 мс) | burst u32 (случайный) |
| `TALK_GRANT` 0x11 | мост → рация | burst u32 |
| `TALK_DENY` 0x12 | мост → рация | burst u32, причина u8: 1 занято, 2 уступи (одновременное нажатие), 3 держит дольше 90 с, 4 мост не знает рацию |
| `TALK_END` 0x13 | рация → мост (3 раза); мост → рации и мосты | burst u32; `src` = кто говорил |
| `TALK_START` 0x14 | мост → мосты | burst u32; `src` = кто говорит |
| `AUDIO` 0x20 | рация → мост → все | burst u32, seq u16, кодек u8 (1), уровень u8, 163 байта AES-128-CTR(k_enc) |
| `PEER_HELLO` 0x30 | мост ↔ мост, раз в 2 с | t_ms u32, t_echo u32, n u8, n × (id u32, flags u8, имя), имя моста |

**Речь:** 16 кГц, кадр 20 мс = 320 отсчётов → IMA ADPCM 4 бит: `pred i16 | index u8 | 160 байт`.
Состояние кодера в каждом кадре — потеря пакета не портит следующие.
Счётчик AES-CTR: `src u32 | burst u32 | seq u16 | 6 нулей` (+1 на каждые 16 байт, как в mbedtls).
Мост речь не расшифровывает: пересылает пакет как есть.

## Эфир (кто говорит)

* Мост даёт эфир первому, кто попросил; остальным — `DENY 1` и сигнал «занято».
* Эфир освобождается по `TALK_END`, через 0,8 с без речи или через 90 с (защита от залипшей кнопки).
* Мосты сообщают друг другу `TALK_START`/`AUDIO`. Если нажали одновременно в двух местах,
  побеждает **меньший id** — одинаково на всех мостах; проигравшему — `DENY 2`.
* Мост не пересылает пакеты от одного моста другому (сеть «звездой» или «каждый с каждым»).

## Обновление прошивки раций

Положить в папку моста `firmware/walkie.bin` и `firmware/walkie.json` (`{"version": N}`).
Мост объявляет версию, размер и sha256 в `HELLO_ACK`; рация, простояв 20 с без разговоров,
скачивает `http://мост:47080/fw/<первые 16 знаков sha>.bin`, сверяет sha256 и только тогда
переключается на новую прошивку. Не сошлось — повтор через час.
